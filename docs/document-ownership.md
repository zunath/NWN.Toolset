# Document ownership guard

`DocumentSession` registers ownership on the mutable nodes in its parsed GFF graph. Typed mutation methods reject edits to owned nodes unless the active `DocumentTransaction` authorizes every owning session. A transaction belongs to one undo stack; `BeginRelated` and `ExecuteRelated` explicitly authorize related sessions and record their edits on that stack. Related sessions must remain alive while the owning stack can undo or redo those edits. `AreaDocumentEditSession` owns the ARE, GIT and GIC sessions together and disposes all three as a group.

The registry uses weak node references so a removed or replaced graph is retained only by live document content or undo history. Per-node owner sets deduplicate a session registration in constant time while tree traversal still visits existing nodes to discover newly attached descendants. Dead weak references are pruned when a document graph is replaced. Disposing a session waits for transactions holding its document lock, refuses disposal from its own active transaction, and releases only that session's ownership token. Detached graph construction remains possible; it cannot bypass a live document's ownership check.

Legacy mutable collections (`JsonGffStruct.Entries`, `JsonGffField.Elements`, and `JsonGffField.LocStringEntries`) remain trusted-only views. Direct mutation through a cast bypasses ownership checks and undo capture; use the typed document methods instead.

The Authoring tests cover async session binding, cross-context and active-transaction disposal, shared-node ownership until the last session releases it, replacement ownership release, nested descendants in replacement graphs, collectible graphs after history eviction, retained undo targets, and grouped GIT/GIC undo/redo and disposal. Release verification passed the focused `DocumentOwnershipTests` filter (13/13) and the full `Nwn.Authoring.Tests` project (75/75, zero skips). The invocations used console output without a TRX logger, so no TRX file was produced.
